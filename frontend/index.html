                              Importar conversaciones

                              ¿Cómo exporto un chat?
                              • WhatsApp: abre el chat → ⋮ (o el nombre del contacto en iPhone) → Más → Exportar chat. Sin archivos genera un .txt; Incluir archivos genera un .zip: súbelo tal cual y las fotos y documentos quedarán enlazados a sus mensajes.
                              • Telegram: en Telegram Desktop, abre el chat → ⋮ → Exportar historial del chat → formato JSON. Sube el archivo result.json.
                              • Email: arrastra un correo desde Outlook o Thunderbird para guardarlo como .eml, o descarga el buzón completo en .mbox (Gmail: Google Takeout → Correo). Los adjuntos de los correos también se guardan.

                              ¿Quién es el cliente?

                              Las conversaciones se guardan como tuyas. Si importas el mismo chat otra vez, solo se añaden los mensajes nuevos.

                                Protección de datos

                                Solo administradores. Para atender solicitudes del cliente: descargar todo lo que guardamos de él (derecho de acceso) o borrarlo por completo (derecho de supresión). Ambas acciones quedan registradas.

                                Unir con otro cliente

                                Si es la misma persona que otro cliente, se pasa todo (conversaciones, datos, tareas, notas…) al cliente elegido y este desaparece. No se puede deshacer.
